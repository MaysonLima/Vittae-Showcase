# Contribuição

Este é um repositório de apresentação do projeto Vittae. O código-fonte principal é mantido em um repositório privado.

Sugestões sobre produto, documentação, UX e arquitetura podem ser discutidas por issues quando o repositório público estiver disponível.

Não envie credenciais, dados pessoais, chaves de API ou outros segredos em issues, commits ou exemplos públicos.
